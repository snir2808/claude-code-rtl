__CHUNKS__

כשמפעילים את ערכת הנושא, התוסף מוסיף בלוק CSS לקובץ הסגנונות של Codex ומעתיק לידו את הגופנים. כשמכבים אותה, הבלוק יוצא והגופנים נמחקים, כך שהקובץ חוזר להיות בדיוק כמו שהיה. כל זה קורה שוב אחרי עדכון של Codex, בפעם הבאה שהחלון נפתח.

When the theme is on, the extension appends a CSS block to the stylesheet of Codex and copies the fonts next to it. When it is off, the block comes out and the fonts are deleted, so the file is exactly as it was. All of this happens again after a Codex update, the next time the window opens.

בדיקת התקינות קוראת את כל קובצי ה־CSS של Codex, אחד אחרי השני, ומחפשת בהם את כל המשתנים והמחלקות שהבלוקים צריכים. אם משהו חסר, מופיעה אזהרה אחת לכל גרסה של Codex, והעיצוב נשאר במקומו בינתיים, עד שהתוסף יתעדכן.

The health check reads every CSS file of Codex, one at a time, and looks for each variable and class the blocks need. If one is missing, a single warning shows for that version of Codex, and the styles stay in place meanwhile, until the extension is updated.
